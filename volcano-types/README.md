# Volcano Lab — Year 10
1. Label the volcano (`index.html`): place each part name, then choose its description. Both are checked independently.
2. Volcano types (`types.html`): read definitions of composite cones, scoria cones, shields and calderas; summarise and compare them.
3. Matching (`sort.html`): select types for 14 photographs. Correct matches reveal explanations; incorrect matches show hints. No written reasons required.

`label.html` also opens the first activity for existing links.
Static HTML/CSS/JavaScript. Responses save on this browser only. Print supports saving as PDF. See sources.html for research and photo credits.
