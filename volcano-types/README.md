# Volcano Lab — Year 10
1. Volcano types: describe and compare the types.
2. Match volcanoes: select types for 16 photographs. Correct matches reveal explanations; incorrect matches show hints. No written reasons required.
3. Label a volcano: place each part name, then choose its description. Both are checked independently.

Static HTML/CSS/JavaScript. Responses save on this browser only. Print supports saving as PDF. See sources.html for research and photo credits.
